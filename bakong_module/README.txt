របៀបប្រើប្រាស់ (HOW TO USE):

1. Copy "bakong_module" folder ទៅដាក់ក្នុង Project ថ្មីរបស់លោកអ្នក។
2. វាយបញ្ជា: npm install node-fetch@2
3. ចម្លងព័ត៌មានបាគងក្នុង .env.example ទៅដាក់ក្នុង .env របស់លោកអ្នក។
4. ប្រើប្រាស់ក្នុងកូដ: 
   const bakong = require('./bakong_module/bakongService');
